# Temperature Converter (Flutter)

A simple assignment-ready Flutter app.

## Features
- Celsius to Fahrenheit conversion
- Fahrenheit to Celsius conversion
- Input validation for empty and invalid values
- Result displayed to 2 decimal places
- Uses `setState`; no database, Firebase, or Supabase

## Run
1. Extract this ZIP file.
2. Open the extracted `temperature_converter` folder in Android Studio.
3. Open the Terminal inside Android Studio.
4. Run:

   ```bash
   flutter pub get
   flutter run
   ```

If Android Studio asks to trust the project, choose **Trust Project**.
